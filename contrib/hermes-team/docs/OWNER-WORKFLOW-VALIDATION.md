# Owner approval workflow

The request lifecycle uses explicit, revision-bound owner decisions. Tests cover requirements approval, optional plan approval, final delivery acceptance, revisions, question answers, queueing, stale decisions, authorization checks, and the separation between an informational status and an approval.

Historical browser and Telegram checks exercised form state, decision display, and handler registration on a self-hosted Hermes installation. They do not attest that another installation is running or that every stage has completed live end to end. See [validation notes](VALIDATION.md).
